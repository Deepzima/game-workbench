Il hub raccoglie capacità condivise per lo sviluppo videoludico: ruoli,
skill, MCP e strumenti. Codice, task e decisioni di ciascun gioco appartengono
al suo repository. I progetti possono essere dentro projects/ o in checkout
esterni, purché la root sia esplicita.

VS Code Agents è l'interfaccia principale; le TUI Codex e Claude sono accessi
alternativi. Il hub è destinato alla distribuzione tramite GitHub e deve
prepararsi con mise senza dipendere dai percorsi personali dell'autore.

gc è un ambiente di apprendimento escluso dal lavoro corrente. La
configurazione OAuth Claude in VS Code è sospesa su richiesta dell'utente.
Per istruzioni vigenti e dettagli consultare sempre le fonti indicate.
